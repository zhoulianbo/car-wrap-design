테슬라 랩핑 만들기는 내 이미지를 배치하는 방법과 AI로 시안을 생성하는 방법으로 시작할 수 있습니다. 두 방식 모두 차량 템플릿과 3D 미리보기를 사용합니다. 디자인을 완성하면 프로젝트를 저장하고 텍스처를 내려받아 Tesla 앱이나 USB를 통해 차량 화면 속 모델에 적용할 수 있습니다.

## 먼저 내 Tesla와 맞는 템플릿을 고르세요

<Link href="/tesla-wrap">테슬라 랩핑 페이지</Link>에서 모델, 연식과 차체를
확인하세요. 현재 스튜디오는 다섯 모델군의 12가지 구성을 제공합니다.

- Model 3: 초기형, 2024 Base, 2024 Performance.
- Model Y: 초기형, 2025 Base, 2025 Premium, 2025 Performance, Model Y L.
- Cybertruck: 2023 구성.
- Model S: 2021, 2025 Plaid.
- Model X: 2021 구성.

<Link href="/tesla-model-3-wrap">모델 3</Link>와
<Link href="/tesla-model-y-wrap">모델 Y</Link> 페이지에서 같은 모델의 버전도
비교할 수 있습니다. 이 명칭은 스튜디오의 미리보기 모델을 구분하기 위한 것이며
판매 지역별 차량명과 사양은 다를 수 있습니다.

이미지를 넣기 전에 차량을 돌려 윤곽, 앞 범퍼와 후면을 내 차와 비교하세요. 초기형에 맞춘 스트라이프가 신형 범퍼에서는 다른 위치에 나타날 수 있고, 긴 측면에서는 반복 패턴 간격이 달라집니다. 시작할 때 전용 템플릿을 고르면 나중에 구도를 다시 잡는 수고를 줄일 수 있습니다.

아직 방향을 정하지 못했다면 <Link href="/gallery">갤러리</Link>를 둘러보세요. 차량 페이지에는 해당 선택에 맞는 공개 작품이 최대 열 개 표시됩니다. 주된 그래픽의 크기, 주변 여백과 선이 끝나는 위치를 살펴보세요. 이미지를 재사용하기 전에는 원작자 조건을 확인하고, 상업적 사용이라면 특히 필요한 권한을 점검하세요.

## 3D로 색상과 마감을 비교하세요

드래그하여 회전하고 확대하여 패널을 살펴보세요. 같은 색과 시점에서 유광, 새틴, 무광, 메탈릭, 펄을 비교하면 마감 차이가 더 잘 보입니다. 기본 팔레트에 원하는 색이 없다면 직접 입력할 수 있습니다.

기존 이미지를 시험하려면 미리보기의 이미지 버튼을 사용하세요. 최대 5 MB의 JPEG, PNG, WebP를 지원합니다. 이 이미지는 브라우저에서 로컬로 읽으며 업로드하거나 프로젝트로 저장하지 않습니다. 이미지를 제거하면 단색으로 돌아가고, 페이지를 새로고침해도 초기화됩니다.

일반 사진이 차체 여러 곳에 조각나 보일 수 있습니다. UV 템플릿이 평면 이미지의 각 부분을 서로 다른 패널에 연결하기 때문입니다. 해당 차량용으로 배열한 텍스처가 판단하기 더 좋습니다. 방향을 정했다면 디자인 시작 버튼을 선택하세요. 임시 이미지는 편집기로 자동 이동하지 않으니 원본 파일을 보관하세요.

## AI로 디자인하기

<Link href="/ai-car-wrap-generator">AI 자동차 랩핑 디자인 생성기</Link>를 열고

차체에서 보고 싶은 요소를 설명하면 됩니다.

참고 이미지로 배색이나 질감을 전달할 수도 있습니다. 업로드 권한이 있는 이미지를 사용하고 어떤 요소를 가져올지 설명하세요. 참고 이미지가 모든 패널에 정확히 맞는 결과를 보장하지는 않습니다.

AI 결과는 한 장의 이미지입니다. 그 안의 글자나 로고는 따로 선택해 이동할 수 없습니다. 내부 디테일을 바꾸려면 설명을 수정해 다시 생성하거나 외부 이미지 편집기를 사용하세요. 결과를 편집기에서 열어 별도의 텍스트, 이미지나 도형을 위에 추가할 수도 있습니다.

## 편집기에서 직접 디자인하기

소재가 이미 있거나 요소마다 직접 배치하고 싶다면 차량별 편집기에서 시작하세요. 예를 들어 <Link href="/create/model-3-legacy">Model 3 초기형 편집기</Link>는 해당 모델의 템플릿을 엽니다. 다른 버전은 선택기에서 바꾸고 업로드·저장 시 로그인 안내를 따라 주세요.

용도에 맞는 해상도의 선명한 원본을 사용하세요. 로고나 삽화를 배경과 조합할 때는 투명 배경 이미지가 편리합니다. 타인의 이미지, 글꼴과 상표를 쓸 권한도 확인하세요.

배경을 정한 뒤 가장 큰 그래픽부터 배치하세요. 차콜 바탕에 밝은 사선 하나를 놓고, 큰 형태가 정리된 뒤 뒤 펜더에 작은 포인트를 추가하는 식입니다. 이동, 크기 조절, 회전과 반전을 사용하세요. 레이어 순서가 앞뒤 관계를 결정하며 불투명도로 겹친 요소의 강도를 조절할 수 있습니다.

## 다운로드 전에 차 전체를 확인하세요

작업 중에도 3D 미리보기로 돌아가세요. 캔버스에서 직선인 요소가 범퍼에서 휘거나 휠 아치 뒤로 사라질 수 있습니다. 크게 수정한 뒤에는 같은 시점을 반복해서 점검하세요.

- 앞면: 보닛, 헤드라이트 가장자리와 범퍼 모서리.
- 양 측면: 도어 이음새, 손잡이, 휠 아치를 가로지르는 그래픽과 반복 요소의 방향.
- 후면: 주된 그래픽이 끝나는 위치와 트렁크·테일게이트·범퍼를 지나는 부분.
- 위쪽: 지붕에서 차체로 이어지는 경계와 예상하지 못한 빈 영역.

마감도 확인하세요. 반사 때문에 잘 보이던 그래픽이 흐려질 수 있습니다. 선이 경계에서 끊기면 레이어를 조정하거나 패널 끝에서 자연스럽게 마무리하세요. 글자가 반전되면 다른 레이어를 뒤집기 전에 해당 UV 영역과 방향을 확인하세요. 지나치게 잘린다면 차량 버전과 템플릿 위 위치부터 점검하세요.

같은 각도에서 수정 전후를 비교하고 더 명확하게 읽히는 버전을 남기세요.

## 프로젝트 저장과 텍스처 다운로드

저장은 계정에 편집 가능한 프로젝트를 보관합니다. 탭을 닫기 전에 완료 표시를 기다리세요. 저장 실패나 버전 충돌 안내가 있다면 먼저 해결하세요. 여러 탭에서 같은 프로젝트를 편집하면 최신 버전을 구분하기 어려울 수 있습니다.

다운로드는 차량 모델에 적용되는 평면 텍스처를 제공합니다. 내려받은 파일을 열어 내용물을 확인하세요. 차량 화면 캡처와는 용도가 다릅니다. 패널을 수정할 때 돌아올 수 있도록 편집 가능한 프로젝트도 보관하세요.

공유·게시 전에는 먼저 저장하고 제목과 이미지에 비공개 정보가 없는지 확인하세요. 디자인 링크는 지인에게 의견을 받거나 시공점과 수정 사항을 논의할 때 유용합니다.

## Tesla 화면에 랩핑 적용하기

커스텀 랩핑은 Tesla 화면 속 차량의 모습을 바꿉니다. 내 차량과 소프트웨어가 이 기능을 지원하는지 확인하세요. 현재 템플릿과 전송 요구 사항은 <a href="https://github.com/teslamotors/custom-wraps" target="_blank" rel="noreferrer">Tesla 공식 커스텀 랩핑 저장소</a>에 있습니다.

### 다운로드 파일 확인

512 × 512~1024 × 1024픽셀, 최대 1 MB의 PNG를 사용하세요. 파일명은 영문자, 숫자, 공백, 밑줄이나 하이픈으로 최대 30자입니다. 다른 형식은 제대로 변환해야 하며 확장자만 바꾸면 안 됩니다. 스튜디오 미리보기가 차량의 파일 수락 여부까지 확인하지는 않으니 실제 파일을 점검하세요.

### Tesla 앱으로 전송

Tesla 앱 4.59.0 이상에서 Creations → Wrap → Upload를 열고 PNG를 선택하세요.

### USB로 전송

exFAT, FAT32(Mac에서는 MS-DOS FAT), ext3 또는 ext4를 사용하세요. NTFS는 지원하지 않습니다. 포맷하면 내용이 삭제되므로 먼저 백업하세요.

드라이브 최상위에 `Wraps` 폴더를 만들고 PNG를 복사한 뒤 데이터 전송을 지원하는 차량 USB 포트에 연결하세요. 같은 드라이브에 지도·펌웨어 업데이트 파일을 넣지 마세요.

### 차량 화면에서 적용

Toybox → Paint Shop → Wraps를 열고 디자인을 선택하세요. 앱과 USB는 각각 최대 열 개를 지원합니다. 메뉴 이름은 언어와 차량 소프트웨어에 따라 달라질 수 있습니다.

## 문제가 생겼을 때

### 차량에 디자인이 표시되지 않아요

PNG 형식, 픽셀 크기, 용량과 파일명을 다시 확인하세요. USB라면 `Wraps` 폴더가 최상위에 있는지, 지원 파일 시스템인지, 지도·펌웨어 업데이트가 없는지 보세요. 메뉴가 없다면 해당 차량의 Tesla 안내를 확인하세요.

### 이미지가 차체에서 조각나 보여요

차량 버전을 확인한 뒤 UV 배치를 보세요. 일반 사진과 템플릿용 텍스처는 배치 방식이 다릅니다. 해당 패널을 3D로 보면서 편집기에서 이미지를 옮기세요.

### 차체 색상을 바꿔도 이미지 색이 그대로예요

텍스처가 적용된 상태에서는 이미지가 차체의 그래픽을 제공합니다. 단색을 비교하려면 이미지를 제거하세요. 마감 조절은 이미지에 닿는 빛의 표현을 계속 바꿉니다.

### 새로고침했더니 미리보기가 사라졌어요

차량 페이지의 미리보기는 임시 상태입니다. 원본을 기기에 보관하고 다시 작업할 프로젝트는 편집기에서 저장하세요.

### 다른 화면에서는 색상이 달라 보여요

화면 밝기, 보정과 주변 조명이 영향을 줍니다. 미리보기로 방향을 비교하되 실물 필름을 구매하기 전에는 실제 샘플을 확인하세요.

## 실제 차량에 시공할 계획이라면

디자인 이미지와 참고 시점을 전문가에게 전달하세요. 차량 치수, 출력 해상도, 도련, 패널 여유분, 늘어남, 소재 특성과 색상 교정을 확인해야 합니다. 디지털 텍스처는 디자인 설명에 도움이 되며, 실차에 맞춘 제작 배치는 별도로 준비해야 합니다.
