## 로컬 미리보기와 저장 파일

차량 페이지의 임시 미리보기용으로만 선택한 이미지는 브라우저에서 처리됩니다. 이 선택만으로 계정에 저장되거나 AI 생성에 제출되지 않습니다. 소재 업로드, 편집기 프로젝트 저장, AI 참고 이미지 제출은 서버 저장 공간을 사용하는 별도 작업입니다.

저장된 프로젝트와 업로드 소재는 앱 데이터베이스와 Cloudflare R2 객체 저장소를 사용합니다. 갤러리에 없는 프로젝트도 반드시 기밀인 것은 아닙니다. 이미지가 공개 저장소 URL로 전달될 수 있어 유효한 주소를 가진 사람은 파일에 접근할 수 있습니다. 목록에 없는 프로젝트나 추측하기 어려운 URL을 민감정보의 안전한 보관 수단으로 여기지 마세요.

## AI 처리와 서비스 제공업체

AI 작업을 제출하면 선택된 API 제공업체에 설명, 디자인 지시와 설정, 차량 템플릿, 결과 생성에 필요한 참고 이미지 또는 URL이 전달됩니다. 당사는 결과와 작업 상태를 받아 계정에 연결된 기록을 저장합니다. 현재 모델과 API 출처는 <Link href="/terms-of-service#ai-models">이용약관의 AI 모델 및 API 제공업체 항목</Link>에 안내되어 있습니다.

OpenAI의 공개 API 정책에 따르면 API 고객이 데이터 공유를 선택하지 않는 한 API 데이터는 기본적으로 모델 학습에 사용되지 않습니다. 다만 [API 데이터 관리 정책](https://developers.openai.com/api/docs/guides/your-data)에 따라 악용 감시, 서비스 운영 또는 법적 의무를 위해 콘텐츠와 관련 기록을 보관할 수 있습니다. 이 방침은 보관 기간이 전혀 없음을 보장하지 않습니다. 외부 업체에 보낼 권한이 없는 자료는 제출하지 마세요.

그 밖에 호스팅·전송·파일 저장을 위한 Cloudflare, 거래·사기 확인을 위한 결제 화면에 표시된 결제사, 활성화된 로그인·이메일 제공업체, 분석·고객지원 업체에 해당 서비스에 필요한 정보를 제공할 수 있습니다. 적법한 요청 준수, 사기·악용 조사, 권리·안전 보호 또는 관련 개인정보 의무를 준수하는 사업 이전을 위해 관련 기록을 공개할 수도 있습니다. 당사는 개인정보를 판매하지 않습니다.

## 공개 갤러리와 공유 링크

크레딧 패키지를 구매하지 않은 계정의 AI 생성물은 갤러리 검토 대상으로 제출됩니다. 자격이 있는 유료 계정은 생성 전에 ‘갤러리에 공개’를 끌 수 있습니다. 승인된 공개 디자인은 갤러리와 사이트 소개 영역에 표시되고 검색엔진에 색인되며, 다른 사용자가 미리 보고 다운로드하거나 변형할 수 있습니다. 공개 정보에는 제목, 차량, 이미지와 기타 게시 항목이 포함될 수 있습니다. 설명은 공개하도록 설정된 경우에만 표시됩니다.

공유 링크를 활성화하면 계정 접근 권한이 없어도 링크를 가진 누구나 미리보기를 볼 수 있습니다. 공유 페이지를 통해 편집 가능한 프로젝트 문서가 공개되지는 않습니다. 제공되는 기능으로 링크를 비활성화하거나 다시 만들 수 있습니다. 디자인 삭제나 링크 비활성화는 타인이 이미 내려받은 사본을 지우지 않으며, 캐시 이미지나 기존 저장소 URL을 즉시 없애는 것도 보장하지 않습니다.

## 보관과 삭제

계정과 저장 콘텐츠는 계정 및 이용 기능 운영에 필요한 동안 유지됩니다. 생성, 크레딧, 결제, 지원과 안전 관련 기록은 오류·분쟁 해결, 악용 방지, 회계·법적 요건 준수를 위해 보관될 수 있습니다. 기간은 기록과 목적에 따라 다르며 모든 정보가 일정 일수 뒤 자동 삭제된다고 보장하지 않습니다.

프로젝트를 삭제하면 활성 프로젝트 목록에서 제거되고 연결된 갤러리 게시물과 공유 페이지가 철회됩니다. 일부 프로젝트·생성 기록은 데이터베이스에 남을 수 있으며 다른 기록이 참조하는 파일도 유지될 수 있습니다. 업로드한 원본 소재는 별도로 삭제해야 하므로 프로젝트 삭제가 소재 삭제를 의미하지는 않습니다. 소재 삭제는 같은 자료를 사용하는 다른 디자인에 영향을 줄 수 있습니다.

계정 폐쇄나 더 넓은 범위의 삭제는 이메일로 요청해 주세요. 법률상 필요하거나 사기 방지, 결제 정산, 법적 청구를 위해 필요한 정보는 보관할 수 있으며 답변 시 관련 제한을 설명합니다. 업체가 보유한 기록, 캐시와 다른 이용자가 저장한 사본은 모두 당사가 직접 통제할 수 있는 대상은 아닙니다.
