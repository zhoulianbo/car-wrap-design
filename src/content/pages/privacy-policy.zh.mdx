## 适用范围与联系方式

本政策说明 carwrapdesign.app 上 {envConfigs.app_name} 的运营方如何在您浏览网站、注册账户、设计车衣、使用 AI、购买积分或分享作品时处理个人信息。隐私问题及数据请求请发送至 [support@carwrapdesign.app](mailto:support@carwrapdesign.app)。服务内容和可接受使用规则详见<Link href="/terms-of-service" className="text-primary font-medium underline underline-offset-4">服务条款</Link>。

## 我们处理的信息

- **账户信息**：邮箱、显示名称、您提供的头像、身份验证记录、账户偏好和登录会话信息。使用本站支持的第三方登录方式时，我们会接收创建及验证账户所需的资料。
- **设计内容**：上传图片、参考图、提示词、所选车型与设计设置、可编辑项目数据、已保存贴图、预览、生成结果，以及公开或分享设置。
- **生成与积分记录**：任务编号、AI 接入方和模型、任务状态、时间、错误、积分冻结、扣除及释放记录。
- **交易信息**：订单编号、所购产品、金额、币种、支付状态，以及支付服务商返回的账单或付款方信息。支付凭据由结账服务商处理，本站应用不保存完整银行卡号或银行卡安全码。
- **技术信息**：访问服务时处理的 IP 地址、浏览器与设备信息、请求及会话记录、错误或安全日志。启用的分析或客服工具可能收集其他使用信息，详见后文。
- **沟通信息**：支持请求、作品举报、反馈，以及处理争议或隐私请求时由您提供的信息。

请勿上传车衣设计不需要的身份证明、支付凭据、敏感个人信息或客户机密。上传涉及他人的素材前，请取得相应授权。

## 本地预览与保存文件

仅在车型页面选择图片进行临时预览时，图片在您的浏览器中处理。选择临时预览本身不会将图片保存到账户，也不会将其提交给 AI。上传素材、保存编辑器项目或提交 AI 参考图是使用服务端存储的独立操作。

已保存的项目与上传素材使用应用数据库及 Cloudflare R2 对象存储。不在广场展示的项目不一定具有保密性：图片文件可能通过公开存储地址提供，任何取得有效地址的人都可能访问文件。请勿将未公开项目或难以猜测的地址当作敏感信息的安全存储方式。

## 信息用途

我们使用信息验证账户、保存与展示设计、运行 AI 任务、提供下载、管理积分、处理购买、提供支持、调查举报、防范滥用、排查故障及履行法律义务。分享和公开设置决定设计如何向其他用户展示。

适用的数据保护法律要求明确处理依据时，我们会根据履行与您的协议、遵守法律义务、在兼顾您权利的前提下维护服务安全及防范欺诈等合法利益，或在需要时取得的同意处理信息。撤回同意不影响撤回前已合法进行的处理。

## AI 处理与服务商

提交 AI 任务时，所选 API 接入方会收到生成所需的提示词、设计指令与设置、车型模板，以及参考图片或其地址。我们接收输出及任务状态，并保存与您账户关联的记录。当前模型和 API 来源见<Link href="/terms-of-service#ai-models" className="text-primary font-medium underline underline-offset-4">服务条款中的“AI 模型与接入来源”</Link>。

根据 OpenAI 公开的 API 政策，API 数据默认不用于训练其模型，但 API 客户主动选择共享数据的情况除外。OpenAI 可能按其 [API 数据控制说明](https://developers.openai.com/api/docs/guides/your-data)，为滥用监测、服务运行或法律义务保留内容和相关记录。本政策不承诺零数据保留。请勿提交您无权传送给外部服务商的素材。

其他接收方可能包括提供托管、内容分发和文件存储的 Cloudflare；结账页面标明、负责交易及反欺诈检查的支付服务商；用于账户服务的已启用登录和邮件服务商；以及已启用的分析或客服服务商。我们会为相应功能共享必要信息。为响应合法请求、调查欺诈或滥用、保护权利与安全，或在遵守适用隐私义务的业务转让中，我们也可能披露相关记录。我们不出售您的个人信息。

## 作品广场与分享链接

未购买过积分包的账户，其 AI 生成作品会开放给广场审核；符合条件的付费账户可在生成前关闭“公开到广场”。审核通过的公开作品可能出现在广场及网站展示区域，被搜索引擎收录，并供其他用户预览、下载或二次创作。公开详情可能包含标题、车型、图片及其他发布字段。仅当作品的发布设置允许公开提示词时，提示词才会展示。

启用分享链接后，任何持有链接的人均可查看预览，无须登录您的账户。分享页面不会向访客提供可编辑项目文档。您可以使用现有控件停用或重新生成分享链接。删除作品或停用链接，不会删除他人已经下载的副本，也不一定立即清除缓存图片或使已有存储地址失效。

## Cookie、浏览器存储与可选工具

我们使用 Cookie 和浏览器存储维持登录会话、语言与外观偏好、广场选项，以及记住积分优惠的交互状态。阻止或清除这些数据，可能导致退出登录或偏好重置。

网站在配置启用时可以加载 Google Analytics 或 Plausible 使用统计、广告脚本，以及 Crisp 或 Tawk 客服组件。启用的工具可能根据其功能和政策接收页面地址、浏览器或设备信息、标识符、交互数据，以及您在客服对话中填写的信息。聊天内容可能包含您主动提供的个人信息。您可通过浏览器管理 Cookie 及站点存储；网站提供同意选项时，也可通过相应选项管理可选处理。本政策不代表每个页面均已有同意管理控件，也不代表列举的工具全部处于启用状态。

## 保留与删除

我们会在运营账户和提供您使用的功能所需期间保留账户及已保存内容。生成、积分、付款、支持及安全记录可能因处理故障或争议、防范滥用、履行会计或法律要求而继续保留。具体期限取决于记录类型和用途；我们不承诺全部数据在固定天数后自动清除。

删除项目会将其从您的有效项目列表中移除，并撤下关联的广场作品和分享页面。部分项目及生成记录可能仍保留在数据库中；文件仍被其他记录引用时，也可能继续存储。上传的源素材有独立删除控件，删除项目不一定同时删除源素材；删除素材可能影响使用同一素材的其他设计。

关闭账户或申请更广泛的数据删除，请发送邮件联系支持。对于法律要求，或防范欺诈、核对支付及处理法律争议所必需的信息，我们可能继续保留，并在回复时说明相关限制。服务商持有的记录、缓存，以及其他用户已保存的副本，并非全部由我们直接控制。
