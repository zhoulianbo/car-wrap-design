# Homepage Content Specification

- Targets: workflow, capability bento, vehicle hubs, FAQ, CTA.
- Workflow uses three named actions without numbered eyebrow labels: Choose a Tesla, Create the wrap, Preview and share.
- Capabilities use an asymmetric bento with six exact cells and varied visual treatment; no generic three-equal-card row.
- Vehicle hubs list exactly the eight launch variants grouped under Model 3 and Model Y, each linking to its canonical model landing or creator route.
- FAQ uses accessible disclosure controls. CTA is a single full-width split surface with one create action and one Gallery action.
- All copy is unique English/Chinese content, contains no unsupported performance or compatibility claims, and avoids visible em/en dashes.
