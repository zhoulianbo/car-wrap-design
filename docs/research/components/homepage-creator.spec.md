# Homepage Creator Specification

- Targets: editor preview, AI generator, and material blocks.
- Editor preview is a real reduced editor composition: left tool rail, central 1:1 UV canvas, right live viewer/preview on desktop; stacked canvas and viewer on mobile.
- AI panel has text and image-reference modes, prompt field, style/base-color options, result count, explicit credit total, and independent results.
- Material row contains Gloss, Satin, Matte, Metallic, and Pearlescent. Each specimen uses the same vehicle/viewer material model as the product.
- Interactive states must be functional. Missing auth/provider/storage states provide direct remediation without starting a paid request.
