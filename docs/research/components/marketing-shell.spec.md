# Marketing Shell Specification

- Targets: `src/blocks/header.tsx`, `src/blocks/footer.tsx`.
- Source: local design at desktop and mobile.
- Header: 80px fixed, deep canvas at 85% opacity, 1px graphite bottom border, 24px/32px horizontal padding, single-line desktop nav, mobile sheet.
- Brand mark: functional emerald C/wrap-line mark, product name text, no competitor asset.
- Active/hover: controls move from muted slate to foreground/active surface over 180ms. Primary AI action uses solid emerald with dark text.
- Footer: five responsive columns, subdued links, one bottom divider, locale selector, copyright, legal disclaimer, `BuiltWithShipAny`.
- Content is supplied from Paraglide message functions. Internal links use locale-aware `Link`.
