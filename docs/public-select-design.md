# 对外 Select 规范

对外页面、作品库、生成器、编辑器和 3D 预览统一使用 `StyledSelect`，不使用浏览器原生 `<select>`。管理后台单独维护。

- 使用现有主题色：浮层底色、细边框、圆角 12px 触发器与 16px 菜单；选中项和焦点使用主色。
- 默认点击高度至少 44px；长标签在触发器截断，菜单显示完整内容。
- 菜单与触发器留 8px 间距，限制可视高度并允许滚动。
- 选中项有对勾；支持键盘导航、输入匹配、Escape 关闭与焦点恢复；每个控件提供可访问名称。
- 使用 Base UI 管理交互。全屏场景将菜单挂载到全屏元素内。
- 通过 options、value 和 onValueChange 传值；不要按页面复制下拉菜单实现。
