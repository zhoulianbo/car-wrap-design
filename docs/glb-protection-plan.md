# GLB 模型交付保护方案

状态：仅方案，未修改存储、部署或加载链路。2026-10-10。

## 当前情况与目标

模型位于 `public/models/`，`src/lib/vehicle-catalog.ts` 提供固定地址，`vehicle-scene.tsx` 通过 GLTFLoader 下载。直接访问静态地址即可获得原文件。轮毂与车身需要使用同一保护策略。

目标是阻止匿名直链搬运、链接长期传播和低成本批量抓取，提高提取成本。浏览器能进行任意角度实时渲染，就必须获得可用几何数据；客户端加密无法保证模型不可导出。Web Crypto 解密仍返回明文 ArrayBuffer，攻击者可以在 GLTFLoader.parse 前截取，或从运行时几何数据导出。WASM、混淆、禁用右键和隐藏扩展名都不能消除这一边界。

## 推荐方案：私有源文件 + 专用预览模型 + 会话授权

1. **源文件隔离**：原始高精度 GLB 移出 public，存入独立私有 R2 bucket，关闭 r2.dev 和直接公开域名访问。上线时同时删除构建静态副本、撤销旧路径并清理旧 CDN 缓存；否则新增鉴权可被旧地址绕过。已被下载的副本无法追回。
2. **只交付预览副本**：离线生成适合网页展示的减面模型，删除无需展示的内饰/隐藏部件、编辑元数据和高精度贴图，保留车衣 UV、材质标识和轮毂挂点。Draco/Meshopt 用于压缩，不称为加密。以纹理对齐、外轮廓和各角度效果验收质量，原始文件不进入前端构建。
3. **Worker 授权网关**：客户端按 slug + version 请求资源，不接收任意 R2 key。Worker 校验车型白名单、版本和会话后通过 R2 binding 读取，前端不接触存储凭证。已登录用户绑定账号会话；首页访客使用服务端签发的短期匿名会话，异常流量才触发挑战，保持首页可直接预览。
4. **短时授权与限流**：建议授权有效期 60–120 秒，绑定模型、版本及会话，限制签发次数、并发下载和请求速率。IP 作为风险信号，避免移动网络切换造成大量误拒。默认允许期限内少量重试；如需一次性令牌，使用 Durable Object 原子消费并定义失败重试，不能只依赖签名或最终一致的 KV。短期 URL 到期不会撤回已下载内容。
5. **缓存必须在鉴权之后**：每次访问先验会话/授权，才读取 Worker 内部按版本复用的缓存或 R2；对外响应采用 private/no-store。CDN 不得直接缓存可匿名读取的网关响应。CORS、Origin/Referer 和 Fetch Metadata 只作为补充信号，不能替代权限校验。
6. **可追溯性**：预览资产记录版本、内容哈希和不含个人数据的资产标记。需要时增加离线几何水印，并验证压缩后仍可识别且不破坏车衣 UV；它用于溯源，不阻止复制。控制日志字段和留存，不记录令牌或密钥。

这一层能显著提高普通下载和批量抓取成本，但通过有效访客/用户会话加载到的预览副本仍可能被提取。

## 是否再加 AES-GCM

可以作为第二阶段的附加障碍：每个资产版本使用独立数据密钥和唯一 nonce，离线生成加密预览副本；主密钥只放服务端安全存储，客户端通过授权接口取得会话可用的解密材料，在内存解密后交给 GLTFLoader.parse。

不建议把固定密钥写入 JavaScript 或 WASM，也不建议为“看起来难破解”定制密码算法。即使 CryptoKey 不可导出，解密结果仍可截获。会话密钥包装主要防止公开复用密钥，不能防止合法会话持有人导出数据。模型分块、频繁轮换和运行时混淆会增加重试、缓存与维护成本，应在真实滥用数据支持下再增加。

优先完成私有源文件、预览副本、授权网关和限流；AES 并不是这些措施的替代品。

## 更强保护：服务端渲染

如果要求客户端拿不到几何数据，应让模型只在服务端 GPU 中加载，客户端发送相机/材质参数并接收图像或视频流。Cloudflare Worker 可负责鉴权与转发，实际渲染需要单独 GPU 服务。代价是并发 GPU 成本、延迟、带宽和交互体验；自由旋转、实时贴图编辑需要专门设计。固定角度可以预渲染，首页也可使用图片预览。

建议本项目先采用授权网页预览副本。高价值、不可交付的源模型采用服务端渲染。

## 实施与验收顺序

- 建立预览资产产线，逐款验证车漆 UV、材质、轮毂和相机；保留源文件恢复能力。
- 实现私有 R2 + Worker 授权、版本映射、会话重试、限流，再改造 GLTFLoader 加载入口。不要先移动线上资源导致页面失效。
- 切换后验证所有旧静态地址失效、私有 bucket 无公开入口、过期/错误会话/未知车型被拒绝，且缓存命中仍需要鉴权。
- 验证首页匿名预览、作品库、编辑器和 3D select 正常；大文件下载、授权过期和并发切换可恢复。
- 用正常浏览器确认真实边界：可授权加载的预览副本仍可被提取；不要把 Network 面板看不到 .glb 当作安全验收。
