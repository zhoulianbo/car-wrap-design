# Tesla 落地页与对外 Select 验收

日期：2026-10-09。验证环境：本地 Vite、现有本地数据库、Codex 浏览器；未部署。

## 改动范围

- 对外 Select 统一为 `StyledSelect`，覆盖作品库筛选/排序、生成器车型、编辑器车型和字体，以及落地页预览车型；后台不在本次范围。
- Tesla 总页覆盖现有车型清单的全部 8 个版本；Model Y 5 个、Model 3 3 个。
- 三页包含 Hero、版本选择、车型作品库、使用步骤、专属 FAQ、CTA。两款车型页另有 FAQ 前的版本比较。
- 预览使用编辑器灰色背景，支持预设/自定义颜色、五种材质、本地图片加载和移除。图片由 createImageBitmap 解码到本地 canvas，没有网络上传调用，刷新即清除。
- 预览底部解释临时预览与编辑器的区别，并提供当前车型编辑器入口。
- 全屏同步 fullscreenchange 和 Escape，画布绝对定位避免尺寸反馈，退出后重新触发测量。
- 修复预览旋转初始状态引起的 SSR hydration 不一致。
- 中英文指南：`/blog/tesla-wrap-complete-guide`，总页 CTA 已连接。注册到现有博客列表和 sitemap 数据源。
